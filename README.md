# Bot500 — Мини-админка рассылок по стартапам (Next.js + Vercel)

Веб-приложение с Telegram-вебхуком и конструктором рассылок из Google Таблиц.

## Что умеет админка
1. **Автоматическое распознавание 40 чатов стартапов**:
   - Когда вы добавляете бота в группу (например, `30211 Marketing Unit`) или в ней появляется любое сообщение, бот считывает первые цифры из названия (`30211`) и привязывает `ID проекта -> Telegram chat_id`.
2. **Конструктор рассылки по Google Таблице («Свой текст + любые столбцы/ячейки»)**:
   - Так как структура таблицы постоянно меняется, вы просто вставляете ссылку на таблицу и нажимаете **«Загрузить столбцы и ячейки»**.
   - Выбираете, в каком столбце сейчас находится `ID проекта` (`A`, `B`, `C`...) и с какой строки начинаются данные.
   - В визуальном редакторе пишете произвольный текст и кликом вставляете кнопки любых столбцов (`{B}`, `{C}`, `{D}` — подставятся значения из строки конкретного стартапа) или конкретных фиксированных ячеек (`{C2}`, `{D1}`).
   - Справа сразу видите **живой предпросмотр** сообщения для каждого из 40 стартапов (и при желании можете подправить текст конкретному стартапу вручную перед отправкой).
3. **Общая или выборочная рассылка**:
   - Отправка единого сообщения всем 40 стартапам или только отмеченным галочкой (поддерживаются теги `{ID}` и `{TITLE}`).

## Быстрый старт и деплой на Vercel

### 1. Создайте бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) и создайте бота (`/newbot`), скопируйте `TELEGRAM_BOT_TOKEN`.
2. В настройках бота у `@BotFather` отключитеGroup Privacy (`/setprivacy` -> `Disable`), чтобы бот видел сообщения в группах и мгновенно запоминал чаты, либо сделайте бота администратором в чатах.

### 2. Задеплойте на Vercel
1. Загрузите этот репозиторий на GitHub / GitLab и импортируйте проект в **Vercel**.
2. В настройках проекта на Vercel (`Settings -> Environment Variables`) добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен вашего бота от `@BotFather`.
   - `ADMIN_PASSWORD` *(необязательно)* — пароль для входа в админку.
   - `DEFAULT_SHEET_URL` *(необязательно)* — ссылка на вашу Google Таблицу по умолчанию.
3. Для постоянного хранения авто-привязанных чатов на Vercel перейдите во вкладку **Storage -> Connect Store -> Upstash Redis (Serverless KV)** (бесплатный тариф). Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся автоматически.
4. После деплоя откройте вашу админку на Vercel, нажмите **«Настройки» -> «Подключить Webhook к этому домену»** (или кнопку **«Активировать Webhook»** во вкладке «База чатов»).

### 3. Локальный запуск
```bash
npm install
cp .env.example .env.local
# Укажите TELEGRAM_BOT_TOKEN в .env.local (или прямо в веб-интерфейсе в кнопке "Настройки")
npm run dev
```
Откройте `http://localhost:3000`.
